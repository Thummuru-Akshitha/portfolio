Akshitha Thummuru — Portfolio

My personal portfolio website: a responsive, single-page site that showcases my education, skills, projects and achievements in cybersecurity, machine learning and web development.

Built for the Full Stack Development (SPC0701CS) Assignment-1.

Live site: https://thummuru-akshitha.github.io/portfolio/ Source code: https://github.com/Thummuru-Akshitha/portfolio

About the site

The portfolio has six sections: Home, About, Education, Skills, Projects and Contact. Its visual style takes inspiration from network graphs, matching my work in cybersecurity and network scanning.

Features
Fully responsive layout that adapts from desktop to mobile
Light and dark themes, with the choice remembered between visits
Project filter to browse by category: Cybersecurity, Machine Learning or Web Development
Contact form with live validation and clear error messages
Accessible by design: semantic HTML, keyboard focus outlines and reduced-motion support
Built with
HTML5 for semantic page structure
CSS3 with custom properties, Flexbox and Grid
Bootstrap 5.3 for the navbar, cards, table, form controls and alerts
JavaScript (ES6+) for the theme toggle, project filter and form validation
Bootstrap Icons and Google Fonts (IBM Plex Mono, Inter)
Project files
index.html holds the page structure and content
style.css holds the design tokens, layout, responsive rules and themes
script.js holds the theme toggle, project filter and form validation
Run it locally
Download or clone this repository.
Open index.html in any browser, or right-click it in VS Code and choose "Open with Live Server".
